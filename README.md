## Engineering Domain
Metallurgical Engineering

## App Description
Load IQ is a mobile application that helps metallurgical engineers and technicians estimate compressive stress on ball mill support structures in real time. Users select a support material, input the load mass and cross-sectional area, and receive an instant colour-coded safety classification (SAFE, WARNING, or CRITICAL) based on the material's yield strength.
